# BackendAI — Medical Supply Demand Forecasting Module

> XGBoost demand forecasting pipeline for SINGULARITY.

## Project Structure

```
BackendAI/
├── data/
│   ├── medical_demand_training_90.csv   ← training dataset (90 rows)
│   ├── test_predictions.csv             ← generated by train.py
│   └── predictions.csv                 ← generated by predict.py
├── models/
│   └── model.pkl                        ← fitted sklearn Pipeline
├── src/
│   ├── features.py       ← feature lists + time-feature engineering
│   ├── preprocessing.py  ← ColumnTransformer (imputers + OneHotEncoder)
│   ├── train.py          ← end-to-end training pipeline
│   ├── predict.py        ← inference on new records
│   ├── forecasting.py    ← high-level API + PuLP stub
│   └── generate_data.py  ← synthetic dataset generator (dev only)
├── requirements.txt
└── README.md
```

## Setup

```bash
# Activate the venv (already created)
.venv\Scripts\activate       # Windows
source .venv/bin/activate    # Linux / macOS

# Install dependencies
pip install -r requirements.txt
```

## Generate Dataset (if not present)

```bash
python src/generate_data.py
```

## Train the Model

```bash
python src/train.py
```

Expected output:
```
Train: 72 rows  (2024-01-01 → ...)
Test :  18 rows  (... → 2024-...)
MAE  : ...
RMSE : ...
R²   : ...
Saved model: models/model.pkl
```

## Run Prediction

```bash
python src/predict.py
# or with custom input:
python src/predict.py --input path/to/new_records.csv --output path/to/out.csv
```

## ML Rules

- Chronological 80/20 split — no shuffling.
- Preprocessing is fit **only** on training data.
- `future_demand` is **never** used as an input feature.
- `model.pkl` is used for inference — the model is **not retrained** during prediction.

## Feature Groups

| Group       | Columns |
|-------------|---------|
| Numeric     | latitude, longitude, current_stock, safety_stock, consumption, patient_load, emergency_demand, outbreak_indicator, lead_time_days |
| Categorical | hospital_id, hospital_name, region_type, medicine_id, medicine_name, medicine_category |
| Time        | year, month, week_of_year, day_of_week, quarter |

## PuLP Integration (Stub)

`forecasting.py` exposes `to_pulp_input(forecast_records)` which classifies hospitals into
**surpluses** and **deficits** based on predicted demand vs. current stock.
Full PuLP redistribution optimization is a separate module.
